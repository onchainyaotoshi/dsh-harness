★ Interaksi tombol Unarchive (Opsi A) — tanpa dialog konfirmasi

klik → busy → baris hilang · reversibel (bisa di-archive lagi kapan pun)
1 · Idle — tombol normal
"Cek seam archive"
workspace: dsh-plugins
2 · Klik — tombol busy (disabled), double-click aman
"Cek seam archive"
workspace: dsh-plugins
3 · Sukses — baris hilang, sesi kembali ke tree workspace (tanpa reload)
(baris dihapus dari daftar · count 2 → 1)
4 · Gagal (jaringan/dsh error) — pesan inline, tombol kembali aktif
"Cek seam archive"
⚠ Gagal: internal-error — coba lagi
Kenapa tanpa konfirmasi: unarchive itu reversibel — sesi bisa di-archive lagi kapan pun lewat menu bawaan. Dialog konfirmasi hanya pantas untuk aksi destruktif/ireversibel (delete permanen — tidak ada di v1). Kalau kamu tetap mau dialog "Unarchive sesi ini?", bisa ditambahkan — bilang saja.
