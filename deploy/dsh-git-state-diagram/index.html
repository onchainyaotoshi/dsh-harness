Cara Kerja dsh-git-state — versi terbaru (event-index)

Strip status git di atas composer Web UI dsh. Di baliknya hanya satu route HTTP: GET /plugins/dsh-git-state/api/state?session=<id> (bukan RPC /api — route ini tidak ikut pagar privileged-method; satu-satunya batasnya: perintah git read-only dengan path dari workspace terdaftar). Versi ini (16 Aug 2026) memakai event-index: workdir tiap sesi dipantau dari stream live, bukan dari baca transkrip.

IstilahArtiContoh
WorkspaceFolder terdaftar di host (registry). Diam, bukan chat./ws
SesiSatu chat. Bisa banyak per workspace. cwd sesi = stempel folder saat sesi dibuat — tidak ikut berubah ketika chat itu cd ke mana pun.Sesi A, B, C
WorktreeCheckout git dalam satu repo: satu checkout utama + N linked worktree (git worktree add)./ws, /ws/.worktrees/feature-a
workdirIndexMap kecil di memori: sesi → workdir bash terakhirnya. Diisi stream live session/event + backfill 1× untuk sesi peminta.{ "sesiB" → ["/ws/.worktrees/feature-a"] }
inUseAda proses hidup yang cwd-nya di dalam worktree itu (dari scan /proc).dev server jalan di feature-a

Gambar 1 — Workspace ≠ sesi, dan cwd ≠ lokasi kerja sekarang

Gambar 2 — Alur satu route hari ini: tiga sumber data + caching

Gambar 3 — Mekanisme workdirIndex: dua sumber pengisi

Sejarah singkat kenapa desainnya begini

  • Percobaan 1 — cwd client: cwd sesi dikira lokasi hidup, ternyata stempel saat sesi dibuat → tag selalu menunjuk worktree utama, linked worktree tak pernah ke-tag. Dibuang (ditemukan code review).
  • Percobaan 2 — readSession ×9: baca transkrip penuh 9 sesi per request, tanpa dedup → event loop dsh jenuh, memori 2.4G→3.3G, situs mati total (insiden 16 Aug 2026). Dedup + memo + batas 1× sudah diterapkan, tapi pendekatannya tetap berat.
  • Final — event-index: pantau stream live session/event, simpan workdir per sesi di Map kecil. Sesi lain: 0 readSession. Sesi peminta: backfill 1×. Benar untuk linked worktree, murah, dan kelas beban insiden hilang total.
Status (16 Aug 2026): versi ini live di produksi & ter-push (commit 9ea9679). Terverifikasi: backfill mengangkat workdir nyata termasuk linked worktree; index live menandai sesi lain; 8 request concurrent berbagi satu jalan; memori flat.
